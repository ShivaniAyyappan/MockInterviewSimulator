AI-Free Mock Interview Simulator (Core Java 17+, no external libraries)

Build :  mkdir out && javac -d out src/mockinterview/*.java && cp res/*.txt out/
Run   :  java -cp out mockinterview.MockInterviewApp          (Swing application)
Tests :  java -cp out mockinterview.TestRunner 3              (iteration 1, 2 or 3)
Metrics: java -cp out mockinterview.Experiment                (figures quoted in Chapter 6)
