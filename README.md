\# Mock Interview Simulator



A Java-based desktop application designed to help students practice mock interviews.



\## Features



\- Interactive mock interview interface

\- Question bank for interview practice

\- Java Swing graphical user interface

\- User can answer interview questions

\- Simple and easy-to-use interface

\- Questions can be modified or expanded



\## Technologies Used



\- Java 17

\- Java Swing

\- Java AWT

\- File Handling
